OpenTaiko 譜面動画版
====================

OpenTaiko 0.5.2.1 に「譜面を動画ファイルに書き出す機能」と
「作譜支援モード」を足したものです。

遊んでいる画面をそのまま録るのではなく、時間を待たずに 1 コマずつ
計算して書き出すので、パソコンが重くてもコマ落ちのない 60fps になります。

入れ替えるのは OpenTaiko.exe と dll\FDK.dll の 2 つだけです。
曲・スキン・設定・BASS などのライブラリは、お使いのものをそのまま使います。


────────────────────────────────────────
入手と更新
────────────────────────────────────────

最新版はここから落とせます（ZIP を 1 つ落とすだけです）。

  https://github.com/ar-ca-na/OpenTaiko-ScoreVideo/releases/latest

一度入れたあとは、OpenTaiko のフォルダにできる「更新する.bat」を
ダブルクリックすると、新しい版があるか調べて、あれば入れ替えます。
入っている版は同じフォルダの scorevideo_version.txt に書いてあります。


────────────────────────────────────────
入れ方
────────────────────────────────────────

【かんたん】
  「適用する.bat」をダブルクリックするだけです。

  ・OpenTaiko のフォルダの中に、この ZIP を展開した場合
      → そのまま実行すれば、自動で入れ替えます
  ・別の場所に展開した場合
      → OpenTaiko.exe が入っているフォルダを
        「適用する.bat」の上へドラッグ＆ドロップしてください

  元の OpenTaiko.exe と dll\FDK.dll は
    OpenTaiko_もとの版.exe / dll\FDK_もとの版.dll
  という名前で残します。戻したいときは名前を戻すだけです。

  ※ OpenTaiko を起動したままだと入れ替えられません。閉じてから実行してください。

【手で入れる場合】
  1. 元の OpenTaiko.exe と dll\FDK.dll を、名前を変えてとっておく
  2. 「中身」フォルダの
       OpenTaiko.exe          → OpenTaiko.exe と同じ場所へ
       dll\FDK.dll            → dll フォルダの中へ
       譜面を動画にする.bat   → OpenTaiko.exe と同じ場所へ
     をコピーする

  ※ FDK.dll も必ず入れ替えてください。全画面が真っ白になる不具合や、
     モニタ間の移動で落ちる不具合の修正がこちらに入っています。


────────────────────────────────────────
必要なもの
────────────────────────────────────────

動画を作るのに ffmpeg が要ります。持っていない場合は

  https://www.gyan.dev/ffmpeg/builds/

から "release essentials" を落として、中の ffmpeg.exe を

  ・OpenTaiko.exe と同じフォルダ           ← いちばん簡単
  ・OpenTaiko.exe と同じ場所に作った ffmpeg フォルダの中
  ・C:\tools\ffmpeg\  または  C:\ffmpeg\bin\
  ・PATH の通った場所

のどれかに置いてください。上から順に探します。
「適用する.bat」は最後に ffmpeg があるかどうかも見て教えます。


────────────────────────────────────────
使い方 その1 : .tja をドロップして書き出す（遊ばない）
────────────────────────────────────────

「譜面を動画にする.bat」に .tja をドラッグ＆ドロップします。
複数まとめて放り込めます。

  1P の難易度を聞かれます（easy / normal / hard / oni / edit）
      Enter だけ押すと「おに」
  2P の難易度を聞かれます（同じ言葉、または none）
      Enter だけ押すと「2P を使わない」

mp4 は .tja と同じ場所に、同じ名前でできます。
同じ名前の動画が既にあるときは、後ろに _2、_3 … が付きます（上書きしません）。

曲名が出る幕から録り、曲の音・太鼓の音（打音）・声が入ります。
音量はゲーム内の設定（楽曲音量・効果音音量・声の音量）に従います。
ただし、曲と打音を足すと音割れする大きさになる場合は、
曲と打音の釣り合いはそのままで、全体を少し小さくして書き出します。

動画に乗せる曲の大きさは、設定画面（System）の次の 2 つで変えられます。
音源のファイルを作り直さなくても、打音との釣り合いを調整できます。

  書出 曲音量を自動   ON にすると、音源の平均の大きさ(RMS)を測り、
                      -9.9dB になるように自動で合わせます（初期値 ON）。
                      目標の値は Config.ini の ExportMusicTargetDb で変えられます。
  書出 曲音量(%)      自動を OFF にしたときの曲の音量。100 で音源そのまま。

曲と譜面の合わせ方は、tja の OFFSET に -0.02 秒を足した値です
（ゲーム内より曲が 0.02 秒早く鳴ります）。

書き出し中は画面が止まって見えますが、故障ではありません。
（表示を後回しにして計算を優先しているためです）

2 分の曲でおよそ 3 分。1280x720 だと 150〜250MB になります。


────────────────────────────────────────
使い方 その2 : 遊びながら録る
────────────────────────────────────────

設定画面の「動画を書き出す」を ON にします。

  たどり方: 曲選択の画面で Shift + F1 → 設定画面
            左のメニューで System → 右のリストの「動画を書き出す」
            （「高DPI対応」のすぐ下）
            左のメニューに戻って Exit で保存

あとは普通に曲を選んで演奏すると、その曲のフォルダに mp4 ができます。
OFF に戻すまで、演奏するたびに書き出します。

こちらも曲の音と打音が入ります。自分が叩いた音がそのまま入ります。


────────────────────────────────────────
作譜支援モード
────────────────────────────────────────

譜面を作る人向けのモードです。
設定画面の「作譜支援モード」を ON にすると、演奏中に次の操作ができます。

  Space        再生 / 停止
  ← →         停止中に 1 小節ずつ移動（素早く 2 回でジャンプポイントへ）
  PgUp / PgDn  停止中にまとめて移動（何小節かは Config.ini の TokkunSkipMeasures）
  Home / End   停止中に最初 / 最後の小節へ
  F5           tja を読み直す（いま居る小節のまま。停止中でも効く）
  F6 / F7      1P / 2P のオートプレイを切り替える
  A            停止中に、その場所へジャンプポイントを付ける

F5 は曲の頭に戻しません。テキストエディタで譜面を直して保存 → F5 で、
その場で反映されます。画面の左上に RELOADED (bar 63) と数秒出ます。
読み込みに失敗したときは RELOAD FAILED と出ます。

画面は本体の「特訓モード」の見た目になります（進行バーと小節番号が出ます）。

※ .tja をドロップして書き出すときは、このモードは自動で OFF になります。
   動画には普通の画面が写ります。


────────────────────────────────────────
マウスで操作する
────────────────────────────────────────

演奏以外のほぼすべての画面をマウスで操作できます。

  ホイール    移動
  左クリック  決定
  右クリック  1つ戻る（演奏中はポーズ）

効く画面: 起動時の注意書き / タイトル・エントリー / 曲選択 / 難易度選択 /
          段位選択 / 設定画面 / 結果画面 / ポーズ画面 / 部屋

2 人プレイのとき、難易度選択画面では
  Shift を押しながらホイール・クリック → 2P 側
になります。

タイトル画面だけは右クリックを割り当てていません。
この画面の「戻る」はゲームの終了なので、うっかり終わらないようにしてあります。


────────────────────────────────────────
コマンドで細かく指定する
────────────────────────────────────────

  OpenTaiko.exe --export "曲.tja" [オプション]

  --out "出力.mp4"      出力先（省略すると .tja と同じ名前）
  --difficulty おに     1P の難易度（easy/normal/hard/oni/edit、省略時 おに）
  --difficulty2 none    2P の難易度。none で 2P を使わない（省略時は設定のまま）
  --fps 60              フレームレート
  --size 1920x1080      出力解像度（省略すると 1280x720 のまま）
  --crf 18              画質。小さいほど高画質・大容量（0〜51、省略時 18）
  --preset medium       圧縮の速さ。ultrafast / veryfast / medium / slow
  --curtain 3           曲名の幕を見せる秒数（省略時 3）
  --music-volume 80     曲の音量(%)。auto で自動（省略時は設定画面のまま）
  --offset-adjust -0.02 tja の OFFSET に足す秒数（省略時 -0.02）
  --ffmpeg "パス"       ffmpeg.exe の場所を直接指定

例:
  OpenTaiko.exe --export "曲.tja" --difficulty oni --size 1920x1080 --crf 20


────────────────────────────────────────
普通に遊ぶとき
────────────────────────────────────────

「動画を書き出す」と「作譜支援モード」が OFF で、--export も付けていなければ、
今まで通りのゲームです。何も変わりません。


────────────────────────────────────────
この版で直した本体の不具合
────────────────────────────────────────

書き出し機能を足すついでに、本体側の不具合も直しています。

・ウィンドウを別のモニタへ動かすと落ちる（FDK.dll）
    ビデオカードが 2 枚ある PC で、別のモニタへドラッグすると
    Direct3D のエラーで強制終了していました。

・ウィンドウを大きくすると画面が真っ白になる（FDK.dll）
    デバイスを作り直したあと、テクスチャを貼り直さずに
    真っ白な板だけを描いていました。0.5.2.1 の全画面が
    使いものにならなかったのはこれが原因です。
    ついでに全画面を「解像度を変えない枠なし最大化」に変えました。
    Alt+Enter でいつでも窓に戻せます。

・曲のフォルダを選ぶと落ちる
    譜面を持たないフォルダを決定すると「パスの形式が無効です」で落ちていました。

・Win+Shift+S や PrintScreen でスクリーンショットが撮れない
    キーボードを占有する設定を外しました。

・「譜面を直接開くモード」（DTXCreator 連携用）で落ちる
    選曲画面を通っていないのに選曲結果を参照していた 5 か所を直しました。

・プレイヤー名や称号が NamePlate.json どおりに出ないことがある
    設定ファイルを「作業フォルダ基準」で読み書きしていたため、
    .tja をドロップして起動すると別の場所に既定値のファイルを作って
    それを読んでいました。exe の隣を見るようにしました。

・演奏記録ファイル（.score.ini）を読むたびに内部で例外が出ていた
    5 行しかない履歴を 7 回読もうとしていました。

・OpenTaiko を開いたまま書き出すと、打音や声が読めない
    音のファイルを他のプロセスに開かせない状態で開いていました。
    これで、遊びながら別窓で書き出すこともできます。

・演奏中の「譜面を読み直す」が働かない
    本体に処理の書かれていない状態を作るだけになっていました。

・書き出した動画で、打音が鳴るたびに曲の音量が下がって聞こえる（v1.1 で修正）
    曲と打音を足した音が上限を超えていて、動画にする段階で
    その瞬間だけ全体が押し下げられていました。

・演奏中に BPM が変わると、キャラの動きが途中の別のコマへ飛ぶ
    BPM が変わる直前のコマから、新しい速さで続けて動くようにしました。

なお全画面は 1280x720 の絵を画面いっぱいに引き伸ばします。
16:10 など 16:9 でないディスプレイでは、そのぶん縦に伸びて見えます。


────────────────────────────────────────
うまくいかないとき
────────────────────────────────────────

・書き出しの出力先に .log ファイルができます。まずそれを見てください。
・「ffmpeg.exe が見つかりません」→ 上の「必要なもの」を確認するか
  --ffmpeg でパスを指定してください。
・起動しない → dll\FDK.dll も入れ替えたか確認してください。
  それでも駄目なら OpenTaiko_もとの版.exe / dll\FDK_もとの版.dll に戻せます。
・Windows が「発行元が不明」と警告することがあります。署名していないためです。
