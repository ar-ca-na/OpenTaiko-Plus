OpenTaiko Plus（OpenTaiko 機能追加版）
========================================

OpenTaiko 0.5.2.1 に機能を足した、非公式の改造版です。
本家（https://github.com/0auBSQ/OpenTaiko）とは関係ありません。
困ったことがあっても、本家には問い合わせないでください。

できること
  ・譜面（.tja）を動画（mp4）にする … 遊ばずに書き出すので、PC が重くてもコマ落ちしません
  ・作譜支援モード …………………… 演奏中に止める・小節を移動する・譜面を読み直す
  ・マウス操作 ………………………… 演奏以外のほぼすべての画面
  ・本体の不具合の修正 ………………… 全画面が真っ白になる、別のモニタへ動かすと落ちる、など

入れ替えるのは OpenTaiko.exe と dll\FDK.dll だけです。
曲・スキン・設定は、今のものをそのまま使えます。


■ 入れ方
──────────────────────────────

【かんたん】ZIP の中の「適用する.bat」をダブルクリック
  ・ZIP を OpenTaiko のフォルダの中に展開した場合は、これだけで入ります。
  ・別の場所に展開した場合は、OpenTaiko.exe があるフォルダを
    「適用する.bat」の上へドラッグ＆ドロップしてください。

【ZIP を使わない】コマンドを 1 行貼るだけ
  1. OpenTaiko.exe があるフォルダを開く
  2. 上のアドレス欄をクリックして  cmd  と入れ、Enter（黒い窓が開きます）
  3. 次の 1 行を貼り付けて Enter

curl -fL -o "%TEMP%\opentaiko_plus.ps1" https://github.com/ar-ca-na/OpenTaiko-Plus/releases/latest/download/install.ps1 && powershell -NoProfile -ExecutionPolicy Bypass -File "%TEMP%\opentaiko_plus.ps1" "%CD%"

どちらの方法でも、
  ・元のファイルは OpenTaiko_もとの版.exe / dll\FDK_もとの版.dll として残します。
    元に戻すときは、名前を戻すだけです。
  ・動画の書き出しに使う ffmpeg が無ければ、自動で入れるか聞きます（y で入ります）。
  ・OpenTaiko を起動したままだと入れ替えられません。閉じてから行ってください。

■ 更新
──────────────────────────────

OpenTaiko のフォルダにある「更新する.bat」をダブルクリックします。
新しい版があれば、落として入れ替えます。
新しい版が出ると、起動したときタイトル画面の上にお知らせが出ます。


■ 譜面を動画にする
──────────────────────────────

【遊ばずに書き出す】
  .tja を「譜面を動画にする.bat」にドラッグ＆ドロップします（まとめて何個でも）。
  難易度を聞かれます。Enter だけなら「1P はおに、2P は使わない」です。
  mp4 は .tja と同じ場所にできます（同じ名前があれば _2 などを付け、上書きしません）。

【遊びながら書き出す】
  設定画面の「動画を書き出す」を ON にすると、演奏するたびに曲のフォルダに mp4 ができます。

  設定画面の開き方: タイトルか曲選択の画面で Shift + F1
                    → 左の System → 右のリストに項目があります

・書き出し中は画面が止まって見えますが、故障ではありません。
・2 分の曲で 3 分ほどかかり、1280x720 で 150〜250MB になります。
・曲の音・太鼓の音・声が入ります。大きさはゲーム内の音量設定どおりです。
  音が割れそうなときは、全体を少しだけ下げて書き出します。

【曲の音量を変える】設定画面（System）
  書出 曲音量を自動   ON（最初から ON）… 曲の大きさを測って、ちょうどよい音量にそろえます
  書出 曲音量(%)      自動を OFF にしたときの曲の音量。100 で元の大きさのまま

  ※ 動画では、譜面の OFFSET に -0.02 秒を足した位置で曲を合わせます（曲が 0.02 秒早く鳴ります）。


■ 作譜支援モード
──────────────────────────────

設定画面の「作譜支援モード」を ON にすると、演奏中に次のキーが使えます。

  Space          再生 / 停止
  ← →           停止中に 1 小節ずつ移動（素早く 2 回でジャンプポイントへ）
  PgUp / PgDn    停止中にまとめて移動
  Home / End     停止中に最初 / 最後の小節へ
  A              停止中に、その場所へジャンプポイントを付ける
  F5             tja を読み直す（いまの小節のまま）
  F6 / F7        1P / 2P のオートを切り替える

テキストエディタで譜面を直して保存 → F5 で、その場で反映されます。


■ マウス操作
──────────────────────────────

  ホイール = 移動 / 左クリック = 決定 / 右クリック = 1 つ戻る
  2 人で遊ぶときの難易度選択は、Shift を押しながらで 2P 側を操作します。
  （タイトル画面の右クリックは、うっかり終了しないよう何もしません）


■ 直した本体の不具合
──────────────────────────────

  ・ウィンドウを大きくする・全画面にすると、画面が真っ白になる
  ・ビデオカードが 2 枚ある PC で、別のモニタへ動かすと落ちる
  ・譜面の入っていないフォルダを選ぶと落ちる
  ・Win+Shift+S や PrintScreen でスクリーンショットが撮れない
  ・プレイヤー名や称号が NamePlate.json どおりに出ないことがある
  ・演奏中の「譜面を読み直す」が働かない
  ・演奏中に BPM が変わると、キャラ・踊り子・モブ・ぷちキャラの動きが途中で飛ぶ
  ・tja の BGIMAGE の背景が出ない（動画では真っ黒になっていた）
  ほか数件。全画面は「解像度を変えない枠なし最大化」にしました（Alt+Enter で窓に戻せます）。


■ うまくいかないとき
──────────────────────────────

  ・書き出した場所にできる .log を見てください。原因が書いてあります。
  ・起動しない → dll\FDK.dll も入れ替わっているか確かめてください。
    だめなら OpenTaiko_もとの版.exe / dll\FDK_もとの版.dll に名前を戻せば元どおりです。
  ・Windows が「発行元が不明」と警告することがあります。署名していないためです。


■ コマンドで細かく指定する（使わなくても困りません）
──────────────────────────────

  OpenTaiko.exe --export "曲.tja" [オプション]

  --out "出力.mp4"       出力先
  --difficulty oni       1P の難易度（easy / normal / hard / oni / edit）
  --difficulty2 none     2P の難易度（none で 2P を使わない）
  --size 1920x1080       解像度（省略時 1280x720）
  --fps 60 / --crf 18 / --preset medium   コマ数・画質・圧縮の速さ
  --curtain 3            曲名の幕を見せる秒数
  --music-volume 80      曲の音量(%)。auto で自動
  --offset-adjust -0.02  OFFSET に足す秒数
  --ffmpeg "パス"        ffmpeg.exe の場所
