> **OpenTaiko（0auBSQ/OpenTaiko）v0.5.2.1 に機能を足した、非公式の改造版です。** 本家とは関係がありません。不具合を本家へ問い合わせないでください。
> 使うには OpenTaiko v0.5.2.1 本体が必要です。

### 変わったこと
- 設定したフォント（Config.ini の `FontName` / `BoxFontName`）が見つからないと、起動するたびに「フォント '…' が見つかりません」のエラーで落ちていたのを直しました
  - Windows に読み込まれていないフォントも、インストール済みのフォントのファイルを探して直接読みます（「自分だけにインストール」したフォントが、再起動後に見つからなくなる場合など）
  - インストールしなくても、OpenTaiko.exe と同じフォルダに `Fonts` フォルダを作ってフォントのファイル（.ttf / .otf / .ttc）を置けば使えます
  - どこにも無いときは MS UI Gothic で表示します

### 入れ方
- **ZIP**: 展開して「適用する.bat」をダブルクリック
- **コマンド 1 行**: OpenTaiko.exe があるフォルダのアドレス欄に `cmd` と入れて Enter し、次を貼って Enter

```bat
curl -fL -o "%TEMP%\opentaiko_plus.ps1" https://github.com/ar-ca-na/OpenTaiko-Plus/releases/latest/download/install.ps1 && powershell -NoProfile -ExecutionPolicy Bypass -File "%TEMP%\opentaiko_plus.ps1" "%CD%"
```

- **前の版から**: ゲームを起動するとタイトル画面の上に「新しい版 v1.5.3 が出ています」と出るので、そのあいだに **U キー**を押してください。または OpenTaiko のフォルダの「更新する.bat」をダブルクリック
- **OpenTaiko.exe をセキュリティソフトに消されたとき**: OpenTaiko のフォルダの「OpenTaiko修復.bat」をダブルクリック
